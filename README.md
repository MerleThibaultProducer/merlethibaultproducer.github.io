# Portfolio – Thibault Merle

Portfolio de Junior Associate Producer (jeu vidéo), publié avec GitHub Pages.

## Modifier le contenu

Tout le contenu se trouve dans `index.html`, dans la partie du script délimitée par
`ZONE À MODIFIER` : textes de présentation, projets (FR et EN), CV et mentions légales
(`LEGAL_FR`, `LEGAL_EN`, `LEGAL_UPDATED`).

Pensez à mettre à jour la date des mentions légales à chaque changement d'hébergeur,
d'adresse e-mail, ou si vous ajoutez un formulaire ou des statistiques de visite.
